# Simple Interest Calculator

A Bash script that calculates simple interest based on user input.

## Description

This project contains `simple-interest.sh`, a command-line calculator that asks for the principal amount, the rate of interest, and the time period, and then prints the simple interest.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input Fields

| Field     | Description                          |
|-----------|--------------------------------------|
| Principal | The initial amount of money          |
| Rate      | Rate of interest (% per year)        |
| Time      | Time period (in years)               |

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

## Example

```
Simple Interest Calculator
Enter principal amount: 1000
Enter rate of interest (% per year): 5
Enter time period (years): 2
Simple Interest = 100.00
```
